A fork from aspy606/minimal-grub-theme
Just like to have it as a fork if the original goes down.
## Installation

```bash
git clone https://github.com/Lummotm/minimal-grub-theme.git
cd minimal-grub-theme
chmod +x install.sh uninstall.sh
sudo ./install.sh
```

## Uninstallation

```bash
sudo ./uninstall.sh
```
